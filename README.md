# LNreader

A self-hosted e-book reader built for Japanese light novels and literature. Upload EPUB or TXT files, read in your browser, and listen to chapter audio generated by a local TTS engine — all running on your own machine.

## Features

### 📚 Library
- Upload EPUB or TXT files via drag-and-drop or file picker
- Book cards show cover image, title, author, chapter count, and upload date
- Delete books from the library
- Supports books of any size

### 📖 Reader
- **Scroll mode** — continuous reading with virtual DOM windowing for performance
- **Paginate mode** — one page at a time with ← → keyboard navigation
- Chapter picker dropdown (jump to any chapter instantly)
- **Display settings** — background color, font size, font family, page width
- Progress is saved automatically every 2 seconds while reading

### 🌐 Translation
- Select any text in the reader, click **Translate**
- Supports three providers: **DeepL**, **Google Translate**, **OpenAI (GPT-4o-mini)**
- Configure provider and API key in Settings

### 🔊 TTS Audio (OmniVoice)
- Generate chapter-by-chapter audio using a locally-running [OmniVoice](https://github.com/k2-fsa/OmniVoice) TTS server
- Background generation — progress shown per-chapter on library cards
- Dedicated **Listening** page (`/listen/:id`) with:
  - Play/pause, seek bar, playback speed control
  - Chapter sidebar with audio availability indicators
  - Auto-advance to the next chapter on completion
  - Resume from last position across sessions

### ⚙️ Settings
- Translation provider selection with API key storage
- TTS voice — upload a reference WAV/MP3 clip for voice cloning
- OmniVoice server URL, port, voice profile, language, model size

### 🔐 Authentication
- **Local dev mode** — click *Continue Locally* for a zero-config JWT session
- **Google OAuth** — sign in with a Google account (requires `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET`)

| Requirement | Notes |
|---|---|
| [Docker](https://docs.docker.com/get-docker/) + [Docker Compose](https://docs.docker.com/compose/) | v2.20+ recommended |
| NVIDIA GPU + [nvidia-container-toolkit](https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/install-guide.html) | Required for the TTS container only |
| `.env` file in `backend/` | See table below |

## Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/youruser/lnreader.git
cd lnreader

# 2. Create backend/.env (see table below)
cp backend/.env.example backend/.env   # or create manually

# 3. Build and start all services
docker compose up --build -d

# 4. Open in browser
open http://localhost:8080
```

> The first startup downloads ~2 GB of CUDA/TTS dependencies. Subsequent starts use cached layers and are fast.

---

## Environment Variables

Create `backend/.env` with the following:

| Variable | Required | Default | Description |
|---|---|---|---|
| `JWT_SECRET` | **yes** | — | Random string used to sign JWTs. Use a long random value. |
| `GOOGLE_CLIENT_ID` | OAuth only | — | Google OAuth app client ID |
| `GOOGLE_CLIENT_SECRET` | OAuth only | — | Google OAuth app client secret |
| `FRONTEND_URL` | no | `http://localhost` | CORS origin and OAuth redirect base |
| `BACKEND_URL` | no | `http://localhost:8000` | Used as OAuth callback URI base |
| `BOOKS_DIR` | no | `/app/books` | Path inside the container where EPUBs are stored |
| `AUDIO_DIR` | no | `/app/audio` | Path inside the container for generated WAV files |
| `DATABASE_URL` | no | `sqlite:////app/data/lnreader.db` | SQLAlchemy database URL |

**Minimal `.env` for local dev (no Google OAuth):**
```env
JWT_SECRET=change-me-to-a-random-string
```

## Services & Ports

| Service | Host Port | Description |
|---|---|---|
| `lnreader-frontend` | **8080** | Angular app served by nginx |
| `lnreader-backend` | internal | FastAPI — only reachable via nginx proxy |
| `lnreader-tts` | **8765** | OmniVoice TTS API (GPU required) |

## Stopping / Resetting

```bash
# Stop without losing data
docker compose down

# Stop and wipe all data (books, DB, audio)
docker compose down -v
```

## Development

To run without Docker for local development:

```bash
# Backend
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000

# Frontend (separate terminal)
cd frontend
npm install
npm start   # proxies /api/* and /auth/* to localhost:8000
```

Frontend dev server: `http://localhost:4200`
